# تطبيق وكيل البطاقة التموينية

تطبيق عربي RTL لإدارة العوائل والمواد والوجبات والتوزيع والمخزون والتقارير، يعمل محليًا بدون إنترنت عبر IndexedDB مع نسخة توافقية في `localStorage`، وجاهز للتغليف عبر Capacitor إلى Android و iOS.

## الدخول الافتراضي

- الوكيل: `agent` / `123456`
- الموظف: `employee` / `123456`

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## تجهيز Android و iOS

```bash
npm run build
npm run cap:add:android
npm run cap:add:ios
npm run cap:sync
```

تم إنشاء مجلدي `android` و `ios` ومزامنتهما مع نسخة الإنتاج. على Windows يمكن فتح `android` في Android Studio وبناء APK/AAB. أما بناء iOS النهائي يحتاج macOS و Xcode و CocoaPods.

## الميزات المنجزة

- تسجيل دخول وتشفير كلمات المرور بـ SHA-256.
- صلاحيات وكيل وموظف.
- إدارة العوائل، البحث، الإيقاف، والحذف بصلاحية الوكيل.
- إدارة المواد والوجبات.
- حساب حصة العائلة تلقائيًا حسب عدد الأفراد وحصة الفرد/العائلة.
- منع التسليم المكرر إلا بصلاحية الوكيل.
- سجل تسليمات قابل للتدقيق.
- مخزون ونسبة توزيع وتنبيهات نقص.
- تقارير قابلة للتصدير JSON.
- نسخ احتياطي واسترجاع.
- واجهة عربية RTL، أزرار كبيرة، ألوان هادئة، ووضع ليلي.
- مجلد Android جاهز ومجلد iOS جاهز للنقل إلى جهاز Mac.
- هيكل جاهز لإضافة المسح بالكاميرا، الرسائل، والمزامنة السحابية.
